## Shared across all briefs
- Same 7-part structure: positioning, offer ladder, proof plan, section order, copy, design, inputs needed.
- Every site has one **signature section** that shows proof live instead of claiming it.
- Prices are placeholders (`$X`) — Faraz sets them.
- Never invent numbers; where a niche has no case study yet, the brief says so.
- Brand thread: Clash Display footer signature on every site; each niche otherwise has its own type and colour.
