## 1. Positioning

**One line:** WordPress development that's fast, secure and easy to edit — custom themes, rescues and care plans from a developer who writes real code.

**Who it's for:**
- Small and mid-size businesses whose WordPress site is slow, hacked, or built on a page builder nobody can maintain.
- Agencies needing a reliable white-label WordPress developer.
- Content-heavy sites (publishers, blogs, membership).

**What they fear:** hacks and malware, plugin conflicts after updates, slow pages, a site only the old developer understood, losing SEO in a rebuild.

**Where Faraz wins:** engineer-level code (custom blocks, headless if needed, integrations), plus the SEO automation background for content sites.

## 6. Design direction

**Concept: "Editorial."** WordPress began as publishing — a confident, magazine-like site.

- **Type:** Instrument Serif (display), Inter (body), JetBrains Mono for metrics.
- **Colour:** paper white `#FAFAF7`, ink text, ultramarine `#3A3AFF` accent, thin rules like a newspaper. Light theme.
- **Motion:** headlines reveal line by line; before/after slider; column rules draw in; restrained — feels editorial, not flashy.
- **Mobile:** single column with pull quotes; slider stays (touch-friendly).
- **Brand thread:** footer signature in Clash Display.
